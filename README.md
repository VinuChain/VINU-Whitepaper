#### Overview

VINU operates on BNB Smart Chain, an EVM based blockchain.&#x20;

#### The VINU Ecosystem

The VINU Ecosystem encompasses a variety of decentralized applications (DApps) and services, including:

1. **VinuSwap**: A zero-gas, lightning-speed decentralized exchange (DEX) that leverages the Uniswap protocol’s principles to facilitate peer-to-peer cryptocurrency exchanges.
2. **VinuFinance**: A DeFi lending platform offering zero-gas loans with innovative features like Zero-Liquidation Loans (ZLLs).
3. **VinuNFT**: A decentralized NFT marketplace where users can buy, sell, and mint their own NFTs.
4. **VinuBurn**: A dashboard for burning and tracking the supply of VINU tokens.
